# Frontier Intelligence — Beta GTM Стратегия v2
*Обновлено: июнь 2026. Стратегия выхода строится вокруг демо Claude Project Template, а не MCP-доступа.*

---

## Принципиальное изменение в GTM

### v1 — «Попробуй наш MCP»
Основной hook: «подключи MCP-сервер и получи доступ к сигналам». Барьер входа высокий — нужно понимать, что такое MCP, как подключать, что делать дальше. Аудитория: технически продвинутые ранние адоптеры.

### v2 — «Получи свой Claude Project»
Основной hook: «установи готовый AI-ассистент для твоей роли в Claude». Барьер входа минимальный — пользователь уже в Claude, один клик открывает Project Template. Аудитория: любой дизайн-лид / PM, кто использует Claude.

**Ключевое следствие:** GTM v2 не объясняет технологию. GTM v2 показывает живой продукт в руках реального пользователя.

## Фаза 0 — Pre-launch (4 недели до запуска)

### Цель
Собрать 30–50 «правильных» бета-пользователей, которые дадут качественную обратную связь и станут первыми case study.

### Действия

**1. Founder Network Activation**
- Личные сообщения 80–100 дизайн-лидам из личной сети (не рассылка — персональные сообщения)
- Формулировка: «Я строю AI-ассистента для дизайн-лидов в Claude. Хочу дать тебе доступ раньше всех и услышать, что работает, а что нет.»
- Цель: 30–40 ответов «да»

**2. Закрытый Telegram-канал**
- Создать канал «Frontier Beta» — 30–50 участников
- Первый контент: 3 тестовых дайджеста (показать формат до продукта)
- Задача: к моменту запуска участники уже знают ценность

**3. Public Signal Channel**
- Отдельный открытый Telegram-канал: «Design Intelligence Brief»
- Еженедельные публичные дайджесты — бесплатно, без регистрации
- Цель: 200–500 подписчиков к launch-дню (proof of concept + warm audience)

**4. Landing Page с waitlist**
- Минимальный лендинг (не полная версия)
- Hero: «AI-ассистент для дизайн-лидов. Работает в Claude.»
- CTA: «Войти в закрытую бету» → email waitlist
- Цель: 300–500 email до публичного запуска

## Фаза 1 — Закрытая бета (недели 1–4)

### Цель
Провалидировать product-market fit: пользователь получает ценность, остаётся, рекомендует.

### Primary GTM Motion: Demo-First

**Не описывай — показывай.**

Вместо того, чтобы объяснять что такое Claude Project Template — дай его в руки. Главный GTM artifact:

> **«Установи Design Lead Edition в Claude за 30 секунд»**

Механика демо-пути:
1. Пользователь получает ссылку на Claude Project Template
2. Открывает в своём Claude (уже имеет аккаунт)
3. Видит живой контекст: «Это твой дизайн-ассистент. Спроси что угодно о трендах в твоей области.»
4. Вводит первый вопрос — получает calibrated ответ в контексте роли
5. Через 24 часа — первый автономный бриф в Telegram

Время от установки до первой ценности: **< 5 минут**

### Onboarding Ritual (первые 7 дней)

| День | Действие | Канал |
|---|---|---|
| День 0 | Установка Claude Project Template | Email / прямая ссылка |
| День 0+4ч | Welcome-сообщение в Telegram: «Твой ассистент активен» | Telegram |
| День 1 | Первый автономный бриф (часть полного) | Telegram |
| День 3 | Email: «Что думаешь? Было ли что-то неожиданно полезным?» | Email |
| День 5 | Тип: «Попробуй спросить [конкретный вопрос по роли]» | Email |
| День 7 | Полный еженедельный дайджест | Telegram |
| День 7+1 | Feedback call с командой (20 мин) | Calendly |

### Закрытая бета: что измеряем

| Метрика | Цель | Тревожный знак |
|---|---|---|
| Установка Project Template | > 80% принятых инвайтов | < 60% → плохой инвайт-флоу |
| Открытие первого бригфа | > 85% | < 70% → проблема с Telegram onboarding |
| Возврат через 7 дней | > 65% | < 50% → нет perceived value |
| NPS после 2 недель | > 50 | < 30 → переосмыслить продукт |
| «Порекомендую коллеге» | > 40% | < 25% → нет виральности |

### Qualitative Learning Sessions
- 10–15 созвонов по 20 минут с бета-пользователями (1 раз в 2 недели)
- Скрипт 3 вопроса: «Что ты делаешь перед тем, как открыть ассистент?» / «Что тебя удивило?» / «Что ты хотел бы, чтобы он делал, чего не делает?»
- Все инсайты → backlog приоритизации

## Фаза 2 — Публичный запуск (недели 5–8)

### Цель
Конвертировать waitlist в платящих, создать первую волну органического роста.

### Launch Week Plan

**День 1 — Product Hunt**
- Запуск на Product Hunt: «AI assistant for design leads, built into Claude»
- Hunter: кто-то с > 500 фолловеров на PH
- Gallery: 5 скриншотов демо (Claude Project открыт, вопрос задан, ответ получен)
- Telegram-бриф как видео: 30-секундный screen recording
- Цель: Top-5 of the day, 300+ upvotes

**День 1 — Community Seeding**
- Посты в: Design Buddies (Slack), Figma Community, Russian Design Telegram, UX Mastery
- Формат: «Я сделал AI-ассистента для дизайн-лидов — вот что он делает за неделю» + скриншоты
- Не реклама — живой опыт раннего пользователя

**День 2–3 — Founder Story**
- LinkedIn пост от основателя: история о том, почему «данных недостаточно — нужен AI, который думает как дизайн-лид»
- Конкретные примеры из beta (с разрешения пользователей)
- Цель: 50+ репостов / 200+ реакций → organic reach

**День 4–5 — Beta User Voices**
- 3–5 коротких цитат от бета-пользователей (с фото/аватаром)
- Формат: tweet-size + 1 конкретный кейс
- Публикация на сайте, LinkedIn, Telegram

**День 7 — Recap + Momentum**
- «Неделя 1 итоги: X установок, Y платящих, вот что говорят пользователи»
- Публичная прозрачность → доверие и FOMO

### Launch Metrics (цели)
| Метрика | Цель |
|---|---|
| Установок за Launch Week | 300–500 |
| Платящих за Launch Week | 50–80 |
| MRR после Launch Week | $3 000–5 000 |
| Product Hunt upvotes | 300+ |
| Telegram-канал подписчики | 1 000+ |

## Фаза 3 — Growth Loop (недели 9–16)

### Primary Growth Loop: Peer Recommendation

```
Дизайн-лид использует ассистент
        ↓
Получает бриф, который оказывается полезным на встрече
        ↓
Делится с коллегой: «посмотри, что мне прислал мой AI-ассистент»
        ↓
Коллега видит конкретный, role-calibrated бриф
        ↓
«Хочу такой же» → устанавливает → платит
```

**Механика подогрева петли:**
- Shareable формат дайджеста: каждый еженедельный бриф имеет «Поделиться»-кнопку в Telegram
- Referral программа: «Пригласи коллегу → 1 месяц бесплатно для вас обоих»
- Public teaser: часть дайджеста (non-sensitive insight) доступна по ссылке без логина

### Content-Led Growth

**Еженедельный public brief** (Design Intelligence Weekly):
- Публичная версия дайджеста в Telegram-канале (без персонализации)
- Реклама: «Хотите персонализированную версию → Design Lead Edition»
- Цель: 2 000–5 000 подписчиков через 3 месяца после запуска

**LinkedIn Thought Leadership:**
- 2 поста в неделю от основателя: реальные инсайты из мониторинга
- Формат: «Вот что произошло в AI + design на этой неделе и почему это важно»
- Не продажи — позиционирование как экспертный голос

**Community AMAs:**
- Ежемесячные «Ask Me Anything» в design-комьюнити (Slack/Discord)
- Тема: «AI-трансформация дизайна: что мы видим в данных»
- Мягкий pitch ассистента в конце

### Partnership Motion

**Figma:**
- Интеграционная история: «Frontier Intelligence + Figma = дизайн-ассистент, который знает твой дизайн-стек»
- Цель: co-marketing материал, возможно упоминание в Figma newsletter

**Anthropic / Claude Ecosystem:**
- Подача в Claude Projects marketplace (если существует к этому моменту)
- Co-marketing: case study «как Claude используется в professional intelligence»
- Потенциальный featured placement в Claude app

**Design Schools / Bootcamps:**
- Партнёрство с DesignLab, Ideo U, Designpreneurs
- Студенческий тариф ($19/мес) → habit formation → конверсия после graduation

## Фаза 4 — PM Edition Launch (недели 17–24)

### Принцип: роль-expansion как GTM-движок

Каждый новый роль-пакет:
1. Открывает новый сегмент (новые ICP)
2. Создаёт cross-sell внутри команд (дизайн-лид + PM)
3. Усиливает brand («Frontier — это для всей product team»)

### PM Edition Launch GTM

**Leverage от Design Lead Edition:**
- 80% дизайн-лидов работают бок о бок с PM → «Возьми Edition для коллеги»
- Team Edition pitch: «Теперь у вас общий контекст в Claude»

**PM-специфичный launch:**
- Product Hunt: отдельный launch «PM Edition — AI assistant for product managers»
- Community: Lenny's Newsletter, Product Hunt community, Slack PM communities
- Founder post: «Почему у PM такой же intelligence-gap, как у дизайн-лидов»

## Каналы, которые НЕ используем на старте

| Канал | Причина |
|---|---|
| Paid ads (Google, Meta) | Слишком рано — нет messaging clarity, высокий CAC |
| Cold email outreach | Не соответствует тональности продукта |
| PR / press releases | Масштаб не тот, effort > reward пока |
| SEO | Долгосрочный канал, не для beta-фазы |
| Sales outbound | После 300+ платящих, не до |

## Ключевые риски GTM и митигация

| Риск | Митигация |
|---|---|
| Claude требует Pro подписку → барьер | Подчеркнуть ценность связки; партнёрство с Anthropic для trial |
| Сложно объяснить «что такое Project Template» | Видео-демо 60 сек; zero-explanation onboarding flow |
| Нет virality, рекомендаций мало | Сделать дайджест shareable по дефолту; referral программа |
| Низкая конверсия trial → paid | A/B test: первый бриф до или после paywall |
| Design-комьюнити восприняли как spam | Founder-first tone; no cold DM; organic content first |
