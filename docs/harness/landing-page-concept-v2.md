## FAQ SECTION

**Q: Do I need to know how to use Claude?**
A: Basic familiarity helps, but your Project Template is pre-configured — you open it and start asking questions. No prompt engineering required.

**Q: What's a Claude Project Template?**
A: A Claude Project is a persistent AI workspace with a pre-set context. Your Frontier template comes with a role-specific system prompt, connected to our live intelligence layer via MCP, with pre-built skills for your most common tasks.

**Q: Does it require a Claude subscription?**
A: Yes, you'll need Claude Pro or higher. We'll guide you through setup.

**Q: How is this different from ChatGPT or Perplexity?**
A: Those are general-purpose AI tools. Frontier is calibrated for your specific role, domain, and level of thinking — and it works autonomously in the background, not just when you ask it something.

**Q: What if my role isn't listed?**

## DESIGN SPECIFICATIONS

### Color Palette
- Background: #0A0A0A (near black)
- Primary accent: #6B5CE7 (electric purple — intelligence, depth)
- Secondary accent: #00D4AA (teal — live data, signals)
- Text primary: #F0F0F0
- Text secondary: #8A8A8A
- Card surface: #141414

### Typography
- H1: 72px / 500 weight / tight leading
- H2: 40px / 400 weight
- Body: 18px / 400 weight / comfortable leading
- Labels: 13px / 500 weight / uppercase / letter-spacing

### Key Interactions
- Role switcher in hero: smooth text morph between "design lead" / "product manager" / "VC analyst"
- Edition cards: hover reveals signal category list
- Telegram mock: animated message delivery effect
- Step 2: Claude Project interface preview on hover

### Above-the-Fold Goal
Visitor must immediately understand:
1. This is for their specific role (not generic)
2. It lives inside Claude (not a new app)
3. It works autonomously (not just on-demand)
