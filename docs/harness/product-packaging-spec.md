## 1. Продуктовая концепция

Frontier Intelligence — это платформа роль-специфичных AI-ассистентов, работающих на живых сигналах. Каждый ассистент — это не просто промпт, а собранная рабочая среда: обученный помощник + инструменты + поток актуальных данных из отрасли.

**Ключевое отличие от generic Claude:** ассистент Frontier знает вашу роль, вашу отрасль и то, что происходит в ней прямо сейчас.

## 2. Тиры подписки

### Starter — «Один ассистент»

**Аудитория:** индивидуальный специалист, который хочет попробовать.

**Что входит:**
- 1 роль-пакет на выбор из каталога
- Доступ к Frontier Workspace этой роли (до 3 тематических кластеров)
- Cowork Skill с базовыми режимами (2 из 4)
- Claude Project Template с предустановленным системным промптом
- Еженедельный дайджест сигналов по роли (email)
- Поддержка: база знаний + community

**Ограничения:**
- 1 активный проект в Claude
- Frontier-сигналы с задержкой 48 ч
- Нет командного доступа
- Нет кастомизации ассистента

**Цена (ориентир):** $29/мес или $290/год

---

### Pro — «Полный ассистент»

**Аудитория:** профессионал, для которого это рабочий инструмент.

**Что входит:**
- До 3 роль-пакетов одновременно
- Полный доступ к Frontier Workspace (все кластеры роли + смежные)
- Cowork Skill с полным набором режимов (все 4)
- Claude Project Template + возможность кастомизации системного промпта
- Frontier-сигналы в реальном времени
- Персональный Workspace: сохранение контекста, история инсайтов
- Еженедельный и ситуативный дайджест
- Экспорт: Markdown, DOCX, PDF
- Поддержка: email, response time 24 ч

**Ограничения:**
- Нет командного управления
- Нет white-label
- Нет API-доступа к Frontier

**Цена (ориентир):** $79/мес или $790/год

---

### Team — «Ассистенты для команды»

**Аудитория:** команды 3–20 человек, руководители, которые хотят единый стандарт.

**Что входит:**
- Неограниченное число роль-пакетов для всех участников
- Командный Workspace: общие контексты, шаблоны, история
- Admin Dashboard: управление ролями участников, доступ к аналитике использования
- Возможность создания кастомных роль-пакетов (на базе шаблонов Frontier)
- Shared Memory: общая база знаний команды, автоматически обновляемая
- SSO (Google, Microsoft)
- Frontier API (read-only, 500 запросов/мес)
- Поддержка: выделенный менеджер, response time 8 ч
- Onboarding-сессия (1 ч) с командой Frontier

**Цена (ориентир):** $249/мес за команду до 5 чел + $39/мес за каждого дополнительного

---

### Enterprise — «Платформа под бренд»

**Аудитория:** корпорации, консалтинговые компании, венчурные фонды, агентства.

**Что входит:**
- Все возможности Team без ограничений
- Разработка кастомных роль-пакетов под нужды организации (до 5 в год)
- Приватный Frontier-workspace: мониторинг только нужных сегментов/отраслей
- White-label: ассистенты под брендом клиента
- Frontier API (полный доступ, неограниченно)
- On-premise или private cloud вариант (по запросу)
- SLA 99.9%, приоритетный инжиниринг
- Quarterly business review с командой Frontier
- Обучение команды (до 40 ч/год)

**Цена (ориентир):** от $2 500/мес, индивидуально

## 3. Роль-пакет: анатомия

Роль-пакет (Role Package) — это атомарная единица поставки Frontier Intelligence. Каждый пакет собирается по единому стандарту.

```
role-package/
├── SYSTEM_PROMPT.md        # Системный промпт с персоной, контекстом, правилами
├── SKILL.md                # Cowork Skill: режимы, команды, воркфлоу
├── WORKSPACE_CONFIG.json   # Настройки Frontier Workspace: кластеры, фильтры, теги
├── DELIVERY_SETTINGS.json  # MCP-коннекторы, уведомления, экспорт
├── MEMORY_TEMPLATE.md      # Стартовая рабочая память (контекст роли)
└── README.md               # Описание для пользователя
```

### 3.1 Системный промпт (SYSTEM_PROMPT.md)

Содержит:
- **Персона:** кто этот ассистент, его экспертиза, стиль общения
- **Контекст роли:** типичные задачи, дилеммы, стейкхолдеры
- **Правила работы:** что делать, чего не делать, как приоритизировать
- **Режимы активации:** ключевые слова, триггеры для переключения режимов
- **Интеграция с Frontier:** как использовать живые сигналы в ответах

Пример структуры системного промпта:
```markdown
## Кто ты
Ты — стратегический дизайн-советник уровня Principal/VP...

## Твои режимы работы
- Vision Advice: когда пользователь просит оценить направление...
- Vision Review: когда присылают артефакт на ревью...

## Как ты работаешь с Frontier
Перед каждым стратегическим ответом проверяй актуальные сигналы...
```

### 3.2 Cowork Skill (SKILL.md)

Инструкции для Claude, как вести себя в Cowork-сессии:
- Описание 3–4 режимов с триггерами
- Форматы вывода для каждого режима
- Правила взаимодействия с MCP-инструментами
- Примеры хороших и плохих ответов

### 3.3 Frontier Workspace Config

## 4. Формат поставки: как клиент получает пакет

### Шаг 1: In-app Installer (основной способ)

Клиент выбирает роль в каталоге → нажимает «Установить» → Frontier автоматически:
1. Создаёт Claude Project с готовым системным промптом
2. Устанавливает Cowork Skill в профиль
3. Подключает Frontier MCP к проекту
4. Инициализирует Workspace с нужными кластерами
5. Запускает стартовый онбординг-диалог

**Технически:** REST API → Claude Projects API + Cowork Plugin API + Frontier MCP config

### Шаг 2: Manual Install (для Enterprise / кастомных пакетов)

Клиент получает `.plugin` файл + инструкцию:
1. Файл импортируется в Cowork через Settings → Plugins → Import
2. Системный промпт копируется в Claude Project вручную или через CLI
3. Frontier Workspace активируется по ключу из письма

### Шаг 3: Team Deployment (для Team / Enterprise)

Admin-панель Frontier:
- Выбор ролей для каждого участника команды
- Batch-деплой через API или CSV-импорт
- Мониторинг статуса установки

## 5. Customer Journey: от регистрации до первого инсайта

### Этап 0: Discovery (до регистрации)

**Точки входа:**
- Органический поиск («AI ассистент для VC аналитика»)
- Реферал от коллеги
- LinkedIn / профессиональные сообщества
- Демо-сессия с командой Frontier

**Что видит пользователь:** лендинг с конкретными примерами инсайтов для его роли, без абстракций.

---

### Этап 1: Регистрация и выбор роли (День 0, ~5 минут)

1. Регистрация (email / Google / GitHub)
2. Вопрос: «Кто вы по роли?» → выбор из 10–15 вариантов с кратким описанием
3. Уточняющий вопрос: «Какая ваша главная задача прямо сейчас?» → контекстуализация
4. Рекомендованный роль-пакет + 1–2 альтернативы
5. Выбор тира (с 14-дневным Pro trial)

---

### Этап 2: Установка (День 0, ~3 минуты)

1. Автоматический деплой (in-app installer)
2. Экран прогресса: «Создаём ваш рабочий профиль...»
3. Краткий тур по интерфейсу (3 слайда): что такое Workspace, как использовать режимы, как читать сигналы
4. Первый вопрос-приглашение от ассистента: «Расскажите о проекте, над которым работаете сейчас»

---

### Этап 3: Первая сессия (День 0–1, ~20 минут)

1. Ассистент задаёт 2–3 вопроса для инициализации рабочей памяти
2. Пользователь описывает задачу в свободной форме
3. Ассистент выбирает режим и отвечает, встраивая 1–2 живых сигнала из Frontier
4. В конце ответа: предложение сохранить инсайт в Workspace
5. Опциональный следующий шаг: «Хотите ревью этого решения?» / «Показать, что пишут конкуренты?»

**Ключевой момент активации:** первый раз, когда пользователь видит живой сигнал из Frontier, которого не было в Google.

---

### Этап 4: Рабочий ритм (Неделя 1–4)

- Ежедневные сессии в Cowork
- Еженедельный дайджест по email с топ-3 сигналами для роли
- Постепенное накопление рабочей памяти (Workspace становится «умнее»)
- Промпты на расширение: «Попробуйте режим X» (обнаружение ценности)
- Нотификации о критических сигналах («В вашей категории появился новый игрок»)

---

### Этап 5: Конвертация и расширение (Месяц 1–3)

- Trial заканчивается → оффер с персонализированным case (что пользователь уже сделал)
- Triager по команде: «Пригласите коллегу → 1 месяц Pro бесплатно»
- Upsell на дополнительный роль-пакет: «Судя по вашим задачам, вам нужен Strategic Consultant»
- Для команд: Admin-флоу с onboarding-сессией

## 7. Принципы продуктовой упаковки

**Принцип 1: Роль первична, инструмент вторичен.**
Пользователь покупает «ассистент для VC-аналитика», а не «доступ к AI с MCP».

**Принцип 2: Живые сигналы — видимая магия.**
В каждом ответе ассистента должен быть хотя бы один инсайт, который невозможно получить от статичной модели.

**Принцип 3: Нарастающая ценность.**
Чем дольше пользователь работает, тем умнее его Workspace — переключение на другой инструмент стоит дорого.

**Принцип 4: Команда умножает ценность.**
Командный workspace ценнее суммы индивидуальных — это главный апселл-рычаг.

**Принцип 5: Простота входа, глубина освоения.**
Первый инсайт — через 20 минут после регистрации. Полный потенциал — через 3 месяца работы.
