## 7. Oracle Cloud Free Tier — честная оценка

### Что изменилось в 2026

С июня 2026 Oracle **урезал** Always Free лимиты:
- **Было**: 4 OCPU + 24 GB RAM (Ampere A1)
- **Стало**: 2 OCPU + 12 GB RAM для новых аккаунтов

### Реальная пригодность для production

❌ **Не рекомендуется для SaaS-продакшена. Причины:**

1. **Capacity shortage**: Shape может быть помечен как Always Free, но ARM A1 инстансы часто недоступны из-за нехватки мощностей в регионе. Новые попытки создать инстанс зависают на "Out of capacity"
2. **Idle reclamation**: Oracle агрессивно рекламирует и уже несколько раз шантинговал free-tier пользователей — если CPU/сеть падает ниже порога, инстанс могут принудительно остановить или заморозить
3. **Reduced limits**: 12 GB RAM на ARM — недостаточно для нашего стека
4. **ARM-совместимость**: Qdrant и Neo4j работают на ARM, но некоторые Docker-образы (особенно старые) могут потребовать дополнительной настройки
5. **Нет гарантий SLA** для Free Tier

**Итог**: Oracle Free Tier — отличная лаборатория для экспериментов, но не production SaaS. Для beta с реальными пользователями это создаст нестабильность и головную боль.

## 8. Fly.io — подходит ли для нашего стека?

### Архитектурная проблема

❌ **Fly.io не подходит для нашего Docker Compose стека. Причины:**

1. **Нет Docker Compose**: Fly.io требует отдельного `fly.toml` для каждого сервиса. Наш стек из 7+ контейнеров = 7+ отдельных приложений
2. **Stateful workloads = Volumes**: Каждый stateful сервис (PostgreSQL, Qdrant, Neo4j, Redis) требует отдельный Fly Volume. Тарификация по провижнингу даже если Machine остановлена
3. **Стоимость взрывается**: Хранилище БД — $0.28/GB provisioned. 100 GB = $28/мес только за хранилище
4. **Нет free tier в 2026**: Отменили постоянный бесплатный tier для Machines и Postgres
5. **Managed Postgres**: Одна реплика production — $82–164/мес

### Ориентировочная стоимость нашего стека на Fly.io

| Сервис | RAM | Цена/мес |
|--------|-----|---------|
| PostgreSQL (1 node) | 2 GB | ~$82 |
| Qdrant (1 node) | 2 GB | ~$25 compute |
| Neo4j (1 node) | 2 GB | ~$25 compute |
| Redis (1 node) | 0.5 GB | ~$7 |
| FastAPI workers (2) | 1 GB | ~$15 |
| Volumes (200 GB total) | — | ~$56 |
| Bandwidth | — | ~$5–20 |
| **Итого** | | **~$215–250/мес** |

**Итог**: Fly.io оптимален для stateless приложений с scale-to-zero. Для нашей архитектуры с несколькими stateful БД — дорого и сложно.

### 🗂️ S3-совместимое хранилище

**Сравнение трёх вариантов:**

| Провайдер | Хранилище | Egress | 1 TB/мес | Интеграция |
|-----------|-----------|--------|----------|------------|
| **Backblaze B2** | $0.006/GB | Бесплатно через Cloudflare CDN | **$6** | S3-совместимый API, boto3 |
| Cloudflare R2 | $0.015/GB | Бесплатно (0 egress всегда) | **$15** | S3-совместимый API |
| Hetzner Object Storage | €0.00659/GB | €1.32/TB | **~€6.6 + egress** | S3-совместимый API |

**Рекомендация для старта:**

**Backblaze B2** — лучшее соотношение цены и функциональности.
- $6/мес за 1 TB хранилища
- Бесплатный egress при использовании через Cloudflare (Bandwidth Alliance)
- Полный S3-совместимый API, boto3/aiobotocore работают из коробки
- Идеально для хранения ingest-артефактов, backup PostgreSQL dumps, Qdrant snapshots

```python
# Пример конфигурации в Docker Compose (env vars):
S3_ENDPOINT=https://s3.us-west-004.backblazeb2.com
S3_BUCKET=frontier-signals
S3_ACCESS_KEY=your_key
S3_SECRET_KEY=your_secret
```

**Когда брать Cloudflare R2:**
- Если сигналы раздаются напрямую через CDN конечным пользователям (zero egress = существенная экономия при 10+ TB/мес)
- Если уже используете Cloudflare для DNS/CDN

**Hetzner Object Storage** — удобно если всё на Hetzner, data residency в ЕС критична. Но дороже B2 при больших объёмах egress.

## Итоговый план действий

```
День 1: Создать Hetzner аккаунт
  → Запустить CX53 в Нюрнберге (NBG1)
  → Настроить Docker + Docker Compose
  → Включить автобэкапы (€5.9/мес)
  → Настроить Floating IP (€0.50/мес)

День 2–3: Поднять стек
  → docker-compose up -d (все 7 сервисов)
  → Nginx с Let's Encrypt
  → Prometheus + Grafana мониторинг

День 7: Объектное хранилище
  → Зарегистрироваться на Backblaze B2
  → Настроить ежедневные backup PostgreSQL → B2
  → Qdrant snapshots → B2 (раз в 6 часов)

Месяц 1–2: Держать на CX53
  → Мониторить RAM/CPU в Grafana
  → При RAM > 24 GB среднем — пора апгрейдиться

Месяц 3–4: Первые paying users → рассмотреть разделение сервисов
```

| IPv4 адрес | €0.50 |

| **Итого** | **~€36–37/мес** |
